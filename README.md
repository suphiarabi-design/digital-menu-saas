# فيترين (Vitrine)

منصة SaaS متعددة المجالات للمتاجر والقوائم الرقمية: طعام ومقاهي، تجميل وعناية، وتجزئة عامة.

## التشغيل

```bash
npm install
npm run dev
```

[افتح موقع فيترين](https://mediaoplus.net)
## المسارات

- `/` الصفحة التسويقية
- `/dashboard` لوحة التاجر (الثيم، المنتجات، QR)
- `/cafe-noor` متجر طعام تجريبي
- `/glow-lab` متجر تجميل تجريبي
- `/bazaar-24` متجر تجزئة تجريبي

البيانات تُحفظ محلياً في المتصفح (`localStorage`) لتبقى التجربة فورية دون خادم.
